PLAYER POINTS PROJECTIONS

FPL Points Projections

Expected points for every player, gameweek by gameweek, sourced from Fantasy Football Scout's Rate My Team tool. Load the data below via manual upload (reliable) or an automated FFS login (experimental) — the table updates and is remembered in this browser either way.

In Fantasy Football Scout, go to RMT Points Projections → Players, set the gameweek range you want, export/copy the table to Excel (columns Player, Team, Pos, GW1…GW38, Total, Price, Value), then upload the .xlsx file here. Nothing leaves your browser — the file is parsed locally.

Experimental. This attempts to sign in to Fantasy Football Scout and pull the Rate My Team players table directly, routed through a public CORS proxy since FFS's members area doesn't allow direct cross-origin requests from other sites. FFS doesn't publish this as an open API, so their login flow can change or block this at any time — treat it as best-effort, not guaranteed. Your credentials are only held in memory for this one request, are never saved to this file or localStorage, and are sent straight to FFS's own login endpoint (not to the proxy) — but because that request still transits a third-party proxy server on the network path, only use this if you're comfortable with that. If it fails, use Manual upload above instead, which always works.

Reads the .xlsx file already committed to this repo (same format as Manual upload: Player, Team, Pos, GW1…GW38, Total, Price, Value) — handy for loading the latest projections on a new machine without re-uploading the file by hand. Works straight away for a public repo; if the repo is private, paste a GitHub token in the Cloud Profile Sync panel below first and this will use it automatically.
